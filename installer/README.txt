EMBER PHONE INSTALLER (WINDOWS)

1. Keep Install Ember.cmd, install.ps1, and Ember.apk in the same folder.
2. On the phone, enable Developer options and USB debugging once:
   Settings > About phone > tap Build number seven times, then
   Settings > System > Developer options > USB debugging.
3. Connect the unlocked phone with a USB data cable.
4. Double-click "Install Ember.cmd" and follow the messages.

The installer downloads Google's official Android platform tools on its first run. It upgrades an
existing compatible Ember installation without deleting its workout data. If Android reports a
signature mismatch, export the old app's data before uninstalling it.
